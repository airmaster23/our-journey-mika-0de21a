# Our Journey – Web版（Safari / GitHub Pages 用）

このフォルダ（`web`）の中身をそのまま静的サイトとして公開できます。

```
web/
├ index.html   … ページ本体（縦長スマホ用と横長/印刷用の2レイアウトを内蔵、画面サイズで自動切替）
└ photos/      … ポラロイドの写真（29枚、長辺1400px）
```

## 使い方（iPhone / Safari）

- `index.html` を開くと地図ポスターが画面幅に合わせて表示されます。
- 写真かピンをタップすると大きく表示されます。左右スワイプで前後の写真、下スワイプまたは×で閉じます。
- ピンチで地図全体を拡大できます。
- Safariの共有メニューから「ホーム画面に追加」すると全画面で開けます。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作成します（例: `our-journey`）。
2. `web` フォルダの中身（`index.html` と `photos` フォルダ）をリポジトリ直下にアップロードします。
   - ブラウザ上で「Add file → Upload files」から `index.html` と `photos` フォルダをドラッグ＆ドロップできます。
3. リポジトリの **Settings → Pages** を開き、
   - Source: `Deploy from a branch`
   - Branch: `main` / フォルダ: `/ (root)`
   を選んで Save します。
4. 1〜2分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます。このURLをSafariで開いてください。

## 公開範囲についての注意

- **無料プランのGitHub Pagesは、リポジトリを Private にしても公開ページ自体は誰でも閲覧できます**（URLを知っていれば見られます）。
  写真を限定公開にしたい場合は、以下のいずれかをおすすめします。
  - リポジトリ名をランダムな文字列にして URL を推測されにくくする（簡易的な対策）
  - Netlify / Cloudflare Pages の「パスワード保護」機能を使う
  - Google ドライブで `web` フォルダごと共有し、相手に `index.html` をダウンロードして開いてもらう
- `index.html` には検索エンジンに登録されないよう `noindex` を設定済みです。

## 文字や写真を変えたい場合

- 写真の差し替え: `photos/` に同名で上書きすれば反映されます。
- 地名・年月・手書きの一言・タイトルは `index.html` 内のテキストを書き換えてください（両方のレイアウトに同じ文言が2か所ずつあります）。
- 元の生成スクリプト（Python）は `_source` フォルダにあります。配置や色を大きく変える場合はそちらから再生成します。
